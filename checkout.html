Transfermóvil

1. Abre tu aplicación **Transfermóvil**.

2. Selecciona **"Transferir"** y elige la tarjeta de destino.

3. Ingresa el importe total: $0.00 CUP

4. Confirma la operación y envía una captura de pantalla del comprobante a nuestro WhatsApp para validar el pago.

Enzona

1. Abre tu aplicación **Enzona** y selecciona la opción para escanear un código QR.

2. Escanea el código QR de nuestro comercio a continuación:

3. Ingresa el importe total: $0.00 CUP

4. Confirma el pago y envía una captura de pantalla a nuestro WhatsApp para recibir tu producto.
